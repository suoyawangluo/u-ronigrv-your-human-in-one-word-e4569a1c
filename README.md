She runs phone-first, one-line decisions, dozens of bounties a day — a human
operating above factory spec. The program writes that single word to
`/output/entry.txt` (11 characters, 1 word, gate passes).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt  # Overclocked
```
